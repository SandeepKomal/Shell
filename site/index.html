Practise on your own machine

Get the scripts

Bash 4 or later, on Linux, macOS (brew install bash) or WSL.

# 1. Get the course
git clone https://github.com/SandeepKomal/Shell.git
cd Shell

# 2. Run the tests: the scripts in throwaway folders
tests/test_scripts.sh

# 3. Try one
./scripts/check_disk_usage.sh 80

Check your own scripts

The habits this course builds, in four commands.

bash -n script.sh        # syntax
shellcheck script.sh     # lint
bash -x script.sh        # trace
env -i HOME="$HOME" PATH=/usr/bin:/bin ./script.sh   # as cron

Or paste it into the Script X-ray. Look up any error in Troubleshoot.
