# Contributing

Contributions that make the scripts safer, clearer, and more useful for day-to-day DevOps and DevSecOps work are welcome.

## Before submitting a pull request

1. Test the script in a safe environment.
2. Run ShellCheck where available.
3. Run `bash -n script.sh` for syntax validation.
4. Avoid destructive defaults.
5. Never commit credentials or secrets.
6. Document required tools, permissions, arguments, and expected exit codes.
7. Explain how the script was tested.

## Good contributions

- Linux administration helpers
- AWS and cloud automation
- Docker and Kubernetes utilities
- CI/CD helpers
- Security checks
- Monitoring and troubleshooting scripts
